# Installer ChessCoach

## Android

1. Ouvrir l’URL HTTPS de ChessCoach dans Chrome.
2. Appuyer sur **Installer l’app** dans ChessCoach ou sur `⋮` puis **Installer l’application**.
3. Confirmer. ChessCoach apparaît ensuite comme une application classique.

## iPhone

1. Ouvrir l’URL dans **Safari**.
2. Appuyer sur **Partager**.
3. Choisir **Sur l’écran d’accueil**, puis **Ajouter**.

## Windows

Ouvrir l’URL dans Chrome ou Edge, puis cliquer sur l’icône d’installation à droite de la barre d’adresse.

## Premier test

1. Ouvrir une première fois l’application avec Internet afin de mettre en cache l’interface et Stockfish Lite.
2. Aller dans **Jouer** et déplacer une pièce par glisser-déposer ou toucher-déplacer.
3. Passer en mode avion et rouvrir l’application pour vérifier le jeu hors ligne.
4. Revenir en ligne puis utiliser **Parties → Synchroniser Chess.com**.

Sur iPhone, l’installation doit être faite depuis Safari. Le bouton automatique d’installation est surtout disponible sur Android et Windows.
